# Basic Demo Projects

A collection of small, practical JavaScript projects built to strengthen core concepts through real examples.

## Projects

1. TaskFlow Kanban: Task management with dynamic UI and state updates.
2. Expense Tracker: Income, expenses, calculations, and form handling.
3. GitHub Profile Finder: GitHub API integration with async/await.
4. QuickNotes: Notes with localStorage and safe DOM rendering.
5. Habit Tracker: Habit progress tracking with persistent storage.
6. Weather Dashboard: City search using public weather APIs.

## What These Projects Cover

- DOM manipulation
- Events and forms
- Arrays and objects
- localStorage
- Fetch and APIs
- async/await
- Error handling
- Dynamic UI rendering
- Responsive layouts

Each project is self-contained and can be run with a local development server such as Live Server.
