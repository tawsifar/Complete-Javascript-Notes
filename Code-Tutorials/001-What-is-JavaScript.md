# What is JavaScript?

JavaScript is a high-level, dynamically typed programming language mainly used to add logic and interactivity to web applications.

## HTML, CSS, and JavaScript

- HTML defines the structure of a webpage.
- CSS controls the styling and presentation.
- JavaScript adds logic, behavior, and interactivity.

Example:

HTML: Creates a button
CSS: Styles the button
JavaScript: Defines what happens when the button is clicked

## Where Does JavaScript Run?

JavaScript can run in web browsers and outside browsers using JavaScript runtimes.

Common JavaScript engines include:

- Chrome: V8
- Firefox: SpiderMonkey
- Safari: JavaScriptCore

Outside the browser, JavaScript can run using environments such as Node.js.

JavaScript can be used for:

- Frontend applications
- Backend applications
- APIs and servers
- Automation
- Web applications

## JavaScript vs Java

Java and JavaScript are different programming languages.

They have different designs, ecosystems, and use cases.

```text
Java is not the same as JavaScript
```

## Important Characteristics

### Dynamically Typed

JavaScript variables do not require an explicitly declared type.

```javascript
let age = 18;
let name = "Tawsif";
```

JavaScript determines the type from the value at runtime.

### High-Level Language

JavaScript provides abstractions that allow developers to work without directly managing low-level computer operations.

### Multi-Paradigm

JavaScript supports multiple programming styles, including:

- Procedural programming
- Object-oriented programming
- Functional programming

### Event-Driven

JavaScript can respond to events such as:

- Mouse clicks
- Keyboard input
- Form submissions
- Scrolling
- User interactions

## Example

A login page can use JavaScript to:

1. User clicks Login
2. Read email and password
3. Validate input
4. Send request to server
5. Receive response
6. Show success or error

This demonstrates how JavaScript handles application logic and behavior.

## Key Points

```text
JavaScript: Programming Language

HTML: Structure
CSS: Styling
JavaScript: Logic and Behavior
```

JavaScript is the language itself, while technologies such as Node.js, React, and Next.js belong to the broader JavaScript ecosystem.
